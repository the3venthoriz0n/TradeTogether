# Skyrim 1.7.104 support

## Goal
Make TradeTogether load and run on Skyrim SE 1.7.104.0 with SKSE 2.3.x.

## Cause
1.7.99+ uses Address Library format 5. SKSE 2.3.x rejects plugins that do not declare
support for it. The ColorGlass vcpkg `commonlibsse-ng` port predates 1.7.99 and cannot.

## Approach
- Replace the ColorGlass vcpkg port with alandtse/CommonLibSSE-NG (`ng` branch, v15.7.3)
  as a git submodule at `lib/commonlibsse-ng`, built via `add_subdirectory`.
- Remove the ColorGlass registry; vcpkg supplies only the fork's dependencies.
- Declare AddressLibraryV5, NoStructUse, AddressLibraryPostAE in the plugin version data.
- Fix compile errors. The code has no vtable hooks, so no vfunc slot shifts are expected.
- Simplify build scripts (drop the baseline-sync script tied to the old registry).
- Bump to 0.12.0 and update README requirements.

## Risks
- The fork is GPL-3.0-or-later; linking it makes this plugin GPL.
- STR Plugin Messaging API and Skyrim Together Reborn must also support 1.7.104.
- Cannot test in-game from here; verification is a successful Release build only.
